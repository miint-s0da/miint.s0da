# PIXELINK 기획서 정리본

출처: Notion `PROJECT 02 | PIXELINK` (2026-11-18 기준)을 지금 사이트(`main`) 기준으로 정리. 사이트와 다른 부분은 사이트를 따르고, 맨 끝 "변경 기록"에 남겼다. 정하지 않은 것은 **미확정**.

## 1. 개요
- 한 줄: 픽셀 그래픽의 레트로 감성과 사이버팝의 선명한 색을 결합한 오리지널 캐릭터 브랜드 쇼룸.
- 방향: **RETRO × CYBERPOP** (레트로 = 시각적 출발점, 사이버팝 = 전체 분위기, 오리지널 캐릭터 = 중심 콘텐츠).
- 태그라인: **PIXEL + NEON, LINKED.**
- 영감: UNI+ON의 컨셉과 무드. 캐릭터와 사이트는 독립적으로 제작.
- 사이트: https://pixel-neon-linked.vercel.app

## 2. 네이밍
PIXELINK = **PIXEL + LINK**.
- PIXEL: 작은 픽셀이 모여 하나의 이미지·캐릭터를 완성하듯, 브랜드의 시각적 정체성.
- LINK: 캐릭터, 아트워크, 세계관, 굿즈를 하나의 경험으로 잇는다는 뜻.
- 픽셀은 장식이나 레트로 스타일이 아니라 콘텐츠와 경험을 연결하는 핵심 디자인 언어.

## 3. 디자인 방향
- 공통 요소: 픽셀 UI · 픽셀 모션 · 네온 발광 · 픽셀 타이포 · 픽셀 그리드.
- 서체: Jersey 10/15/20/25(타이틀·로고), Press Start 2P(라벨), Inter / Noto Sans KR(본문), NeoDunggeunmo(한글 제목·라벨).
- 지금 사이트의 시각 언어: 장난감·스티커·폴라로이드. 카드 타이틀바·로딩바 같은 시스템(HUD) 문법은 쓰지 않는다.
- 커서(PC): 린키 전신 픽셀 스프라이트, 링크 위에서 통통 뜀.
- 호버: 섹션마다 다른 반응. 떠오름+빛은 쓰지 않는다. 버튼 호버 `#FF2FCB`.

## 4. 컬러

| 면 / 보조 | 파스텔 핑크 `#FFB5D8` | 연핑크 `#FFD6EC` |

## 5. 캐릭터
| 이름 | 역할 | 설정 |
|---|---|---|
| **CHI:EE** (치이) | 메인 | SD 2등신 인간형, 블루·핑크 투톤 트윈테일, 블랙·화이트 사이버 스트리트웨어, 귀·꼬리 없음 |
| **LEENKI** (린키) | 보조 / 안내자 | 픽셀 고양이 백신. 화이트 몸체, 핑크·블루 블록, 시안 얼굴 화면 눈. CHI:EE의 질문에 답하는 백과사전 같은 역할 |
| **GLEEN** (글린) | 보조 / 글리치 | 데이터 정령. 밝은 딥 퍼플 몸체, 핑크 발광 눈, 블루→핑크 이펙트. 에러와 글리치 이벤트에서 등장 |

- 제작 형태: 2D 일러스트 + 3D 피규어 (3D는 (추후)).
- 캐릭터 디자인은 확정 원본을 기준으로 고정하고, 사이트는 새 콘텐츠를 추가하는 방식으로 운영한다.
- GLEEN 시트는 수정 중이므로 완성 후 상세 등록.

## 6. 사이트 구성
메인은 한 페이지(인트로 포함), 상세는 서브페이지.

| 번호 | 메뉴 | 서브메뉴 (기획안) |
|---|---|---|
| CH.01 | CHARACTERS | 전체 캐릭터 / CHI:EE / LEENKI / GLEEN / 캐릭터 데이터베이스 |
| CH.02 | ARTWORK | 전체 아트워크 / 캐릭터 일러스트 / SD 아트 / 2D 디자인 시트 / 3D 피규어 / 애니메이션 (+ 드레스룸 입구) |
| CH.03 | WORLD | 세계관 소개 / 캐릭터 다이어리 / 캐릭터 에피소드 / 스페셜 콘텐츠 |
| CH.04 | GOODS | 전체 상품 / 피규어 & 컬렉터블 / 의류 / 캐릭터 액세서리 / 디지털 굿즈 / 스티커 & 문구 |
| CH.05 | BRAND | 브랜드 소개 / 브랜드 아이덴티티 / 디자인 시스템 / 공식 채널 |
| CH.06 | UPDATES | 공지사항 / 신규 아트워크 / 신상품 소식 / 프로젝트 업데이트 |

메인 화면 순서: 인트로 → 히어로(BLINK TWICE IF YOU'RE HERE. → THEY SAW YOU FIRST. → CHI:EE ♡ → 한글 소개 → PRESS START →) → 티커 → CH.01~06 섹션 → 푸터.

현재 상태: 섹션 본문은 대부분 구성되어 있고, 서브페이지는 드레스룸만 있다. 실제 아트워크·굿즈·세계관·업데이트 내용은 (추후).

## 7. 드레스업 (드레스룸)
- 캐릭터 설정창 같은 구성: 왼쪽 CHI:EE 미리보기, 오른쪽 의상 선택, 선택 즉시 적용, 종이인형 스타일.
- 패키지 의상·소품과 연결해 실제 굿즈 체험으로 잇는 것이 목표.
- **1단계(구현됨)**: `dress.html`. 의상 2종(기본 / 의상 컬렉션) 교체(픽셀 모자이크 전환), 린키 문답 말풍선(확인된 사실만, 나머지 (추후)), 실물 굿즈 칸(COMING SOON).
- 다음 단계(미확정): 아이템별 레이어 종이인형(같은 캔버스의 아이템 이미지 필요), 코디 카드 저장·공유, 구매 코드 해제(서버 필요).
- 도감·코디 카드를 모으는 방식이며 포인트·코인은 쓰지 않는다.
- 흐름: 입는다 → 알게 된다(LEENKI 설명) → 모은다 → 갖는다(실물 굿즈).

## 8. 동작·체험 결정
- 인트로: 카세트 삽입 연출. 처음 방문에만(30일), SKIP/Esc, 메인의 INTRO 버튼으로 재시청, `?skipintro`.
- 소리: 호버·클릭마다 8비트 효과음, 섹션·캐릭터별 다른 소리, 5단계 볼륨 + 음소거.
- 히어로: 쇼룸 이미지는 고정, 겹침 효과만. 모바일은 효과 축소.
- 반응형 + PWA(홈 화면 추가, 오프라인).

## 9. 미확정

- 드레스룸 의상 이름·설명, 실물 굿즈 연결
