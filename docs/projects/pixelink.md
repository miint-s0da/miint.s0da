# PIXELINK

- 한 줄: 치이(CHI:EE)와 픽셀 세계를 잇는 오리지널 캐릭터 IP 브랜드 사이트
- 상태: 제작 중 · 재작업 예정
- 사이트: https://pixel-neon-linked.vercel.app
- 출발점: UNI+ON의 히어로 캐릭터
- 역할: 캐릭터 경험 설계 (인트로·커서·호버), 브랜드 확장 구조, 인터랙션
- 콘셉트: 레트로 픽셀 + 파스텔 네온
